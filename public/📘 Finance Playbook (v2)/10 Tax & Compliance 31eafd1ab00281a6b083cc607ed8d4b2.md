## Sales Tax

### Ongoing Process

- TaxJar handles automated sales tax calculation, filing, and remittance
- Finance responsibility: verify TaxJar is actually filing correctly

### Monthly Filing Check (15th of each month)

1. Log into TaxJar dashboard
2. Confirm all state filings for prior month were submitted
3. Check for any failed filings or error alerts
4. Verify amounts filed match expected revenue by state
5. Flag any new nexus states triggered by employee hires or volume thresholds

### Quarterly Deep Check

1. Reconcile TaxJar filed amounts against QBO revenue by state
2. Verify tax rates are correct for each jurisdiction
3. Confirm all states where Breeze has nexus are being filed
4. Review any exemption certificates on file
5. Check for regulatory notices or correspondence

## State Licensing (Money Transmitter Licenses)

### Overview

As a payment processor, Breeze requires Money Transmitter Licenses (MTLs) in states where it operates. This is an ongoing compliance workload.

### Monthly Process

- Review application tracker: which states are pending, approved, or not yet started
- Check for any outstanding documentation requests from state regulators
- Confirm renewal deadlines are tracked and actioned ahead of time
- Coordinate with legal on new state applications

### Tracker Requirements

- State name + license type
- Application status (Not Started / Applied / Pending Review / Approved / Renewal Due)
- Key dates (application date, expected decision, renewal date)
- Outstanding requirements per state
- Point of contact (internal + external counsel)
